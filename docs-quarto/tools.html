R packages

ToolsRTM

Leaf, canopy and soil radiative transfer models, LUT generation, sensor convolution and trait inversion. It includes PROSPECT, FLUSPECT, Liberty, fourSAIL, foursail2, INFORM, MARMIT and SPART workflows.

  • R tutorials →

SCOPEinR

R interface to SCOPE for coupled canopy radiative transfer, photosynthesis, energy balance, land-surface temperature and sun-induced chlorophyll fluorescence (SIF).

  • R tutorials →

Python libraries

toolsrtm

Python port of the ToolsRTM core, including leaf and canopy models, spectral indices, sensor convolution, STAC satellite retrieval and classical and deep learning inversion.

  • Python tutorials →

scopeinpython

Python implementation of the SCOPE workflow for batch simulations of reflectance, fluorescence, photosynthesis, temperature and energy-balance outputs.

  • Python tutorials →

Interactive applications

ToolsRTM.app

Nine point-and-click Shiny applications expose PROSAIL, PROSAIL-BRDF, MARMIT, SPART, SCOPE, LUT generation, RTM comparison, inversion and STAC workflows. In R, launch them through ToolsRTM::get.simulator().
